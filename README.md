# gh-pages

Data store for [`benchmark-action/github-action-benchmark`](https://github.com/benchmark-action/github-action-benchmark),
used by [`.github/workflows/benchmarks.yml`](../../blob/dev/.github/workflows/benchmarks.yml). This
branch holds historical BenchmarkDotNet results only — it is **not** the source for GitHub Pages (that's
configured to deploy from GitHub Actions; see `.github/workflows/docs.yml`), so nothing here is served.

Do not edit this branch by hand — the action manages it.
